# ✉️ AI Email Helper

AI Email Helper is a small hobby project exploring how AI can help people write emails more easily.

The project lets users work with different writing styles and generate email content through a simple interface.

## ✨ Features

* Email input
* Different writing styles
* AI-assisted email generation
* Simple user interface

## 💡 What I wanted to learn

This project allowed me to explore:

* AI-powered writing tools
* User input
* Different writing styles
* Interactive web applications
* Building practical tools around an idea

## 🛠️ Technologies

* HTML
* CSS
* JavaScript
